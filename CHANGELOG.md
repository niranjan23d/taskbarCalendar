# Changelog

All notable changes to this Outlook-only fork are recorded here.

## 2.2.4 - 2026-11-16

- Expanded local title-word icon matching with classic Fugue icons for planning, presentations, development, data, security, research, release, finance, customer, calls, social events, wellness, breaks, home working, global meetings, and metrics.

## 2.2.3 - 2026-11-16

- Removed an embedded author email address from Settings so the published build contains no personal contact detail.

## 2.2.2 - 2026-11-16

- Added a hover-only inline join icon to joinable current and upcoming meeting rows. Each icon opens its own Outlook invitation link; cancelled, past, linkless, and privacy-masked rows do not expose it.
- Reverted the Notes torn-paper edge to the fuller original profile and softened the sharpest points.
- Made Segoe UI the legacy font fallback as well as the per-element Notes default, preserving the shipped typography for fresh and migrated settings.

## 2.2.0 - 2026-11-16

- Made the current Notes appearance the shipped default, including the lighter paper, leather binding, torn-paper layers, 5 px card corners, and taskbar colours.
- Added the Notes-card date stamp: independently styled day number, month, and weekday.
- Added Settings-preview drag placement for each date-stamp element. The live hover card remains read-only.
- Made the date stamp reserve its paper area so meeting text and rules do not draw through it.
- Added 12-hour clock support that measures the complete AM/PM range without ellipsis.
- Improved the torn-paper edge with a darker lower sheet that appears only where it protrudes beneath the upper tear.
- Kept preview and live detail cards on the same renderer.

## 2.1.2

- Corporate preview release.
